# Security

Openbook is a self-hosted Convex app. It is not a multi-tenant SaaS. Do not
put live Stripe keys, session cookies, or real user data into issues,
fixtures, or pull requests. Tests and screenshots in this repository use
synthetic accounts.

Please do not disclose security issues in a public issue.

Use GitHub's private vulnerability reporting for this repository. If it is
unavailable, contact [@nstranquist](https://github.com/nstranquist) privately
before public disclosure.
